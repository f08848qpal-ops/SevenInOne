# SevenInOne
 SevenInOne v1.12 MIUIx 风格的 ColorOS / OnePlus SystemUI 七合一 2×2 聚合磁贴模块。 ## 功能 - 在系统“添加磁贴”页面添加「七合一」2×2 磁贴 - 支持从本机 SystemUI 检测可添加磁贴 - 二级页面支持 3 个大卡片和 4 个小卡片 - 点击配置页中的圆盘即可更换对应磁贴 - 支持任意检测到的磁贴放入七个槽位 - 支持 2×2 磁贴进入二级页面的缩放、位移动画 - 支持二级页面卡片进入系统原生磁贴菜单 - 设置页磁贴名称优先使用 ROM 当前语言的官方名称 ## 作者与声明 作者：我真的不姓峰_ 本项目免费、开源，仅供学习和个人使用。 禁止未经授权搬运、冒名发布、售卖，或利用本项目收费、圈米。
